Module name: seq_detect. Ports: input clk, input rst, input din, output found (all 1 bit).
A Moore finite state machine that detects the bit pattern 1011 on din. One bit of din is
sampled on each rising edge of clk. Overlapping matches count: in the input 1011011 the
pattern is found twice, because the last 1 of the first match is also the first 1 of the second.
rst is synchronous and active-high: if rst is 1 on a rising edge, the machine forgets all
previous bits. found depends only on the stored state, never directly on the current din.
After each rising edge, found is 1 exactly when the last four bits sampled (oldest first)
were 1, 0, 1, 1, and 0 otherwise. found must be 0 after reset.
