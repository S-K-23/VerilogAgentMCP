Module name: alu. Ports: input [7:0] a, input [7:0] b, input [2:0] op, output [7:0] y, output zero.
A purely combinational 8-bit ALU with no clock. All values are unsigned. y is selected by op:
0: y = a + b (keep only the low 8 bits, so 255 + 1 = 0)
1: y = a - b (keep only the low 8 bits, so 0 - 1 = 255)
2: y = a AND b, bit by bit
3: y = a OR b, bit by bit
4: y = a XOR b, bit by bit
5: y = 1 if a < b (unsigned comparison), otherwise y = 0
6: y = a shifted left by the value of b[2:0] only (the low 3 bits of b, 0 to 7); the upper bits of b are ignored
7: y = 0
zero is 1 when y equals 0, and 0 otherwise, for every op.
